# 787 飞行俱乐部

基于 Three.js 的浏览器三维飞行游戏，包含程序化 787-9 模型、海岛机场、起飞与降落、10 个航点、3 种视角、键盘与触控驾驶、仪表和可选音效。飞行模型为娱乐用的街机简化模型。

在线试玩：[787 飞行俱乐部](https://dreamliner-flight-zyk.ardentelk3.chatgpt.site/)

## 本地运行

需要 Node.js 18 或更新版本。无需安装依赖：

```sh
node server.mjs
```

浏览器打开 http://127.0.0.1:8878/ 。Three.js 已随项目保存，首次运行也无需在线下载游戏引擎。可选的在线字体不可用时会使用系统字体。

## 操作

| 操作 | 按键 |
| --- | --- |
| 抬头 / 低头 | W / S，或 ↑ / ↓ |
| 向左 / 向右转弯 | A / D，或 ← / → |
| 左 / 右方向舵 | Q / E |
| 加 / 减油门 | Shift / X，或屏幕油门滑块 |
| 收放起落架 | G |
| 收放襟翼 | F |
| 地面刹车 | 空格 |
| 切换视角 | C |
| 暂停 / 继续 | P / Esc |
| 重新开始 | R |

触屏使用左下摇杆和屏幕按钮。飞行中切换到其他窗口会自动暂停。

从跑道起飞时加油门，在 135 KT 左右按 W 拉起。穿过 10 个绿色圆环后对准 09 跑道，减速、放轮、放襟翼，平稳接地并刹车。初学者也可选择“直接进入空中”。

## 检查

```sh
node flight.test.mjs
```

## 文件

- `dist/game.js`：游戏循环、任务、镜头、界面与输入
- `dist/flight.js`：独立飞行动力学
- `dist/aircraft.js`：787 程序化几何与动作
- `dist/world.js`：地形、海水、机场与场景
- `dist/vendor/three.module.js`：Three.js r160，MIT 许可见 `THREE-LICENSE.txt`

飞机长、翼展参考波音公开规格；场景为虚构，模型与飞行动力学不用于航空训练。
